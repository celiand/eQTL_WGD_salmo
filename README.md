## General information
These scripts are related to article Large-scale eQTL analyses in Atlantic salmon reveals persistent dosage compensation 100 million years after genome duplication.


All scripts can be found in the scripts folder.


## Trans eQTL connections analysis
Scripts for Figure 1 can be found in <ins>Fig_1_bin_expression.R</ins>

The script <ins>eQTL_gene_pair_defintion_and_shuffle_boostrap.R</ins> is used to classify the eQTL-gene connections and plot the figure 2. The classification logic is depicted in <ins>decision_tree</ins>

The script <ins>intra_chromosome_connections.R</ins> is used to make supplementary figure 1.

The script <ins>Enrichment_AOre_LORe_inter_homologs.R</ins> is used to plot supplementary figure 2.




## Ohnolog expression analysis and dosage compensation

The scripts <ins>ohnologs pair analysis.R</ins> <ins>and Rescuing_pair</ins> respectively analysis the correlation of ohnolog expression and the dosage compensated pairs (Figures 3, 4; supplementary figures 4,6).
